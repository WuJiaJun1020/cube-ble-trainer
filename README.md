# Rubik Trainer - PySide6 精简版

本版本已移除“公式练习 / 公式广场 / 公式录入 / 公式训练”等相关逻辑，仅保留：

1. 计时练习
2. 魔方求解器

## 运行

```bash
pip install -r requirements.txt
python main.py
```

## 保留功能

### 计时练习

- 随机打乱
- 观察 / 计时
- 放弃还原
- 分步成绩弹窗
- 历史记录与回放
- 今日练习摘要
- 3D 魔方显示与实体魔方输入处理

### 魔方求解器

- 自动 / 历史求解模式切换
- Solve 生成还原引导
- Exit 退出引导
- Reset 重置
- 手动转动按钮
- 随机打乱
- 3D 魔方求解过程显示

- 公式广场
- CFOP / F2L / OLL / PLL 公式库管理
- 公式录入、编辑、删除
- 多解法管理
- 自动录入

- 公式训练、公式训练计时与训练记录

## 本次调整

### 求解器 3D 魔方大小

求解器页面的 3D 魔方已缩小。需要继续微调时，修改 `ui/main_window.py` 顶部的常量：

```python
SOLVER_CUBE_ZOOM = -8.2
```

规则：数值越小/越负，魔方越小；数值越接近 0，魔方越大。例如 `-8.6` 会比 `-8.2` 更小，`-7.8` 会更大。

### 求解器初始朝向

魔方求解器顶部新增“初始朝向”下拉框，前两项为：

1. 白顶绿前（默认）
2. 黄顶绿前

切换后会立即同步 3D 魔方视角。求解器内点击 `Reset` 会重置为当前选择朝向下的还原状态。

## 本次修复：求解器初始朝向

- “初始朝向”不再只是切换相机角度，而是会按所选顶色/前色重建求解器的还原态魔方。
- 例如选择“黄顶绿前”后：黄色中心在 U 面，绿色中心在 F 面；Reset 也会回到该朝向下的还原态。
- 自动求解器现在根据当前 6 个中心块动态识别 U/R/F/D/L/B，不再固定假设 W=U、Y=D，因此不同初始朝向下的还原态也会被正确识别。
- 求解器魔方大小参数在 `ui/main_window.py` 顶部：`SOLVER_CUBE_ZOOM = -8.2`。数值越负越小。

## 2026-05 修复说明

- 计时训练固定使用白顶绿前还原态与打乱方式。
- 从计时训练切回魔方求解器时，会自动按当前“初始朝向”下拉框恢复求解器还原态，避免显示为黄顶绿前但内部仍是白顶绿前。
- 求解器 3D 魔方缩放参数在 `ui/main_window.py` 顶部：`SOLVER_CUBE_ZOOM = -10.0`。数值越负魔方越小。

## 本次修复：蓝牙魔方面转随求解器初始朝向映射

- GAN 蓝牙魔方上报的是固定配色坐标系下的面转：U=白、D=黄、F=绿、B=蓝、R=红、L=橙。
- 求解器选择“黄顶绿前”时，会把蓝牙上报的面转映射到当前显示坐标系：例如黄色顶层上报为 D，会同步成 3D 魔方的 U，转动屏幕上的黄色顶面。
- 计时训练仍固定白顶绿前，不受求解器初始朝向影响。

## 本版修复

- 修复求解器引导中用户做错步骤后，程序立即基于旧 cubies 状态重新求解的问题。
- 现在会等待 3D 魔方动画提交完成后，再根据当前真实魔方状态重新生成剩余解法。
- 连续输入错误步骤时，会先累计到当前状态，待动作队列空闲后统一重新计算，避免继续使用旧引导步骤。

## 本版修复：求解器做错步骤优先补偿

- 求解器引导过程中，如果用户额外做错一步，会先把错误步骤记录下来，并把下一步改成该步骤的反向补偿。
- 例如当前应转 `R`，但用户多转了 `U`，界面会提示先补偿 `U'`，补偿后继续原来的 `R`。
- 如果用户在同一面转错方向或次数，会给出最短同面修正；例如应转 `R'` 但转了 `R`，下一步会提示 `R2`。
- 仍保留自动重新求解逻辑作为兜底。

## 本版新增：求解器 R2/U2 半步跟随

- 魔方求解器中，`R2`、`U2` 等双转步骤现在支持像计时训练一样的半步跟随显示。
  - 第一次同面 90° 转动后，当前步骤 chip 会显示绿蓝半圆，表示已完成一半。
  - 第二次同方向 90° 转动后，才会进入下一步。
  - 如果第二次反向转动导致抵消，会继续提示重新完成该双转。
- 预留“调试板块”导航入口，调试功能实现已移除。
  - 输入长度必须为 10。
  - 仅允许 `x/y/z/X/Y/Z` 字母串。
  - 小写表示正转：`x/y/z`。
  - 大写表示反转：`X/Y/Z` 会识别为 `x'/y'/z'`。
  - 按步骤执行时，系统会逐步提示正确/错误，并高亮当前应执行步骤。
